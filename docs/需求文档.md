# 需求文档（草稿）

> 状态：草稿 · 待小组评审后冻结为 v1.0。此后修改须在提交信息中注明 `docs(requirements): ...` 并说明变更原因。

## 1. 一句话说明

给古诗词学习者提供一个可闯关练习、可错题复习、可追溯诗人生平地理足迹的 Web 平台，解决“背了就忘、练习无反馈、诗人背景零散”的问题。

## 2. 目标用户

| 角色 | 典型诉求 |
| --- | --- |
| 学生（普通用户） | 按关卡练习诗词、查看错题、按计划复习、浏览诗人地图 |
| 管理员 | 维护诗词与诗人数据、管理用户与角色、查看使用情况 |

## 3. 范围（In Scope）

| 编号 | 模块 | 范围说明 |
| --- | --- | --- |
| M1 | 登录 / 注册 | 注册、登录、登出、登录态保持、按角色进入不同首页 |
| M2 | 诗词库管理 | 诗词的新增、删除、修改、查询；按朝代 / 作者 / 标签筛选 |
| M3 | 闯关模式 | 关卡列表、答题、即时判分、通关判定、成绩记录 |
| M4 | 复习模式 | 错题本、收藏、按复习计划推送待复习诗词、掌握度统计 |
| M5 | 管理员 / 用户 | 角色权限区分、用户列表与禁用、内容维护入口 |
| M6 | 诗人生平地图 | 诗人档案、生平时间线、生平地点在地图上的可视化 |

## 4. 明确不做（Out of Scope）

1. 不做移动端 App 与小程序，只交付 Web 端。
2. 不做支付、会员、广告等商业化功能。
3. 不做 AI 自动生成诗词或自动出题，题目全部来自题库与既定规则。
4. 不做多学校 / 多租户隔离，单实例部署即可。
5. 不做实时对战与社交聊天。

## 5. 功能需求与验收标准

> 验收标准必须可核对，禁止“能正常运行”这类表述。

| 编号 | 功能 | 输入 | 输出 | 验收标准 |
| --- | --- | --- | --- | --- |
| F1 | 注册 | 用户名、密码、确认密码 | 注册结果提示 | 用户名重复时返回明确提示且不创建账号；两次密码不一致时拒绝提交 |
| F2 | 登录 | 用户名、密码 | 进入对应角色首页 | 密码错误时提示且停留在登录页；未登录访问受保护页面被重定向到登录页 |
| F3 | 新增诗词 | 标题、作者、朝代、正文、标签 | 列表中出现新记录 | 必填项为空时逐项提示；保存后刷新页面数据仍存在 |
| F4 | 删除诗词 | 选中的诗词 | 列表移除该记录 | 删除前二次确认；删除后关联的闯关 / 复习记录有兜底处理 |
| F5 | 闯关答题 | 关卡、作答选项 | 得分与对错解析 | 答错显示正确答案与解析；重复进入关卡可看到历史最高分 |
| F6 | 复习 | 错题 / 收藏的诗词 | 待复习列表与掌握度 | 答错的诗词进入错题本；复习完成后掌握度随之更新 |
| F7 | 权限控制 | 不同角色账号 | 菜单与接口访问结果 | 普通用户访问管理员接口返回 403；管理员可看到用户管理入口 |
| F8 | 诗人生平地图 | 诗人生平地点数据 | 地图标记与时间线 | 点击标记显示地点、年份、事件；无坐标数据的诗人有时间线兜底展示 |

## 6. 非功能需求

- 本地环境常规页面响应时间 < 1 秒（不含首次加载）。
- 兼容 Chrome / Edge 最新版本。
- 演示数据必须脱敏，不得包含真实姓名、学号。
- 所有密钥通过环境变量注入，仓库内不得出现明文。
