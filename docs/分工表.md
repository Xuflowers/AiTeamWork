## 2. 填写与核对规则

1. 分工必须落到具体文件或目录，写“负责前端”不算完成。
2. 每人至少保留一条可读的提交记录，禁止代提交。
3. 合并前由组长核对：模块负责人与 `git shortlog -sn` 是否一致。
4. 分工调整需在本文件更新并在提交信息中注明 `docs(division): ...`。
5. 答辩前由组长导出 `git shortlog -sn` 与 `git log --oneline` 存档到 `docs/test-reports/` 或汇报材料。
