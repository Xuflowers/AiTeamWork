## 2. 主干与边界用例（至少 3 类边界）

| 编号 | 类型 | 用例 | 预期结果 |
| --- | --- | --- | --- |
| T1 | 主干 | 正确账号密码登录 | 登录成功，进入对应角色首页 |
| T2 | 主干 | 新增诗词后列表可见 | 数据持久化，刷新后仍存在 |
| T3 | 主干 | 完成一关并提交 | 返回得分与解析，成绩入库 |
| T4 | 边界-空值 | 注册时用户名或密码为空 | 拒绝提交并提示具体字段 |
| T5 | 边界-超长 | 标题 / 正文超过长度上限 | 截断提示或拒绝保存，服务不报 500 |
| T6 | 边界-非法类型 | 路径参数传非数字 id | 返回 400，不抛堆栈 |
| T7 | 边界-越权 | 普通用户调用管理员接口 | 返回 403 |
| T8 | 边界-重复 | 重复提交同一关卡答案 | 不重复计分或幂等处理 |

## 3. 测试证据要求

- 每次提交测试结果保存到 `docs/test-reports/`（截图或测试框架输出文件均可）。
- 报告中需能看到执行时间、通过 / 失败数量。
- 失败用例不得删除，修复后保留前后对比。

## 4. 加分项：变异测试（+2 分）

- Java 项目使用 PIT（pitest），Node 项目使用 Stryker。
- 对判分、复习计划等核心逻辑生成变异体，记录变异覆盖率与存活变异体分析。
- 存活变异体需在本文档说明“为何不影响正确性”或补测试。

## 5. 安全清单

| 项目 | 要求 | 自查 |
| --- | --- | --- |
| 密钥管理 | 数据库密码、`JWT_SECRET`、第三方 Key 全部走环境变量 | [ ] |
| 仓库洁净 | `.env` 不入库；提交前检查暂存区无密钥 | [ ] |
| 密码存储 | 使用 BCrypt 等加盐哈希，禁止明文 / MD5 | [ ] |
| SQL 注入 | 使用参数化查询或 ORM，禁止字符串拼接 SQL | [ ] |
| XSS | 用户输入渲染时转义，富文本做白名单过滤 | [ ] |
| 权限校验 | 后端逐接口校验角色，不能只靠前端隐藏菜单 | [ ] |
| 依赖来源 | 第三方依赖与技能记录来源与用途 | [ ] |
| 数据脱敏 | 演示数据不含真实姓名、学号、手机号 | [ ] |
