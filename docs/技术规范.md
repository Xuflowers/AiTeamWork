## 2. 数据模型（初稿）

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| `users` | id, username, password_hash, role, status, created_at | role: `ADMIN` / `USER`；密码只存哈希 |
| `poets` | id, name, dynasty, birth_year, death_year, bio | 诗人档案 |
| `poet_places` | id, poet_id, place_name, lng, lat, year, event | 生平地点，供地图与时间线使用 |
| `poems` | id, title, poet_id, dynasty, content, translation, appreciation, tags | 诗词主体 |
| `levels` | id, name, order_no, difficulty, description | 闯关关卡 |
| `questions` | id, level_id, poem_id, type, stem, options, answer, analysis | 题目及解析 |
| `challenge_records` | id, user_id, level_id, score, passed, created_at | 闯关成绩 |
| `review_items` | id, user_id, poem_id, wrong_count, last_review_at, next_review_at, mastery | 复习与掌握度 |
| `favorites` | id, user_id, poem_id, created_at | 收藏 |

关系：`poets 1—N poems`、`poets 1—N poet_places`、`levels 1—N questions`、`users 1—N challenge_records / review_items / favorites`。

## 4. 接口约定

- 风格：RESTful，统一前缀 `/api/v1`。
- 鉴权：请求头 `Authorization: Bearer <token>`。
- 统一响应体：

```json
{ "code": 0, "message": "ok", "data": {} }
```

- 分页参数：`page`、`size`；分页响应 `data: { list: [], total: 0 }`。
- 主要接口：

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/api/v1/auth/register` | 注册 | 公开 |
| POST | `/api/v1/auth/login` | 登录，返回 token | 公开 |
| GET | `/api/v1/poems` | 诗词列表 / 筛选 | 登录 |
| POST | `/api/v1/poems` | 新增诗词 | 登录 |
| DELETE | `/api/v1/poems/{id}` | 删除诗词 | 登录 |
| GET | `/api/v1/levels` | 关卡列表 | 登录 |
| POST | `/api/v1/challenge/{levelId}/submit` | 提交作答 | 登录 |
| GET | `/api/v1/review/plan` | 待复习列表 | 登录 |
| GET | `/api/v1/poets/{id}/map` | 诗人生平地图数据 | 登录 |
| GET | `/api/v1/admin/users` | 用户列表 | 管理员 |

## 5. 错误处理策略

| 场景 | HTTP 状态 | code | 处理方式 |
| --- | --- | --- | --- |
| 参数校验失败 | 400 | 40001 | 返回字段级错误信息，前端逐项提示 |
| 未登录 / token 失效 | 401 | 40101 | 前端清除登录态并跳转登录页 |
| 无权限 | 403 | 40301 | 前端提示无权限，不暴露资源内容 |
| 资源不存在 | 404 | 40401 | 返回统一提示，不返回堆栈 |
| 服务器异常 | 500 | 50001 | 服务端记录日志，前端提示“请稍后重试” |

原则：对外不暴露堆栈与 SQL；所有异常由全局异常处理器统一转换。
